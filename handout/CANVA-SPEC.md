# Canva-Spezifikation — Handout „Der Gaza-Konflikt"

Werte 1:1 aus `Gaza_Konfliktanalyse_Grundlage_11.09.pptx` übernommen, damit das
Handout farblich exakt zur Präsentation passt.

## Dokument
- Format: **A4 hoch**, 210 × 297 mm, 2 Seiten
- Seitenrand: **11,6 mm** (44 px bei 96 dpi) links/rechts

## Farben (Hex, direkt in Canva eingeben)

| Rolle | Hex | Verwendung |
|---|---|---|
| Seitenhintergrund | `#EFE7DA` | Grundfläche beider Seiten |
| Dunkelblau (Bänder) | `#1A2A41` | Kopfband Seite 1, Fazit-Band Seite 2 |
| Marineblau (Text) | `#132741` | Überschriften, Hervorhebungen |
| Schieferblau (Fließtext) | `#4A5C73` | Alle Aufzählungen und Fließtexte |
| Terrakotta (Akzent) | `#A6462B` | Nummern, Icons, Aufzählungspunkte, Merksätze |
| Oliv (Labels) | `#8A8069` | Kleinüberschriften, Quellen, Fußnoten |
| Sand (Flächen) | `#E3DACA` | Getönte Kästen (Leitfrage, Kennzahlen, Zitatblöcke) |
| Linien | `#CFC6B4` | Trennlinien zwischen Abschnitten |
| Hell auf Dunkel | `#C3CBD1` | Sekundärtext auf den dunklen Bändern |
| Lachs (Kicker) | `#D9A184` | Kleinüberschrift auf dunklem Grund |

## Typografie — Arial durchgehend (wie in der Präsentation)

| Element | Größe | Stil |
|---|---|---|
| Haupttitel | 30 px / ca. 23 pt | fett |
| Untertitel | 15 px / ca. 11 pt | normal |
| Kicker (HANDOUT · …) | 11,5 px | fett, Versalien, Laufweite +0,16 em |
| Abschnittstitel (01 …) | 13 px | fett, Versalien, Laufweite +0,07 em |
| Kleinüberschrift (Labels) | 11,5 px | fett, Versalien, Laufweite +0,07 em |
| Fließtext / Aufzählung | 14,5–15 px / ca. 11 pt | Zeilenabstand 1,22–1,28 |
| Kennzahlen | 19 px | fett, Terrakotta |
| Quellen | 9,5 px | Zeilenabstand 1,3 |

## Aufbau
- **Aufzählungspunkt:** kleines **Quadrat** 5 × 5 px in Terrakotta, kein Rundpunkt
- **Abschnittstrenner:** 1 px Linie `#CFC6B4` **über** jedem Abschnitt
- **Icons:** Linien-Icons (Kontur 2 px, Terrakotta, 17 px) — Ortsmarke, Personen,
  Zielkreuz, Kompass, Waage, Schild, Puls, Globus, Kettenglied
- Keine Farbbalken an Kastenrändern, keine Linien unter Titeln

- **Seite 1:** Kopfband (Formalien) · Leitfrage · zweispaltig 01–04 · 05 über volle Breite · Fußzeile
- **Seite 2:** Kolumnentitel · 06 über volle Breite · zweispaltig 07/08 · 09 über volle Breite · Fazit-Band · Quellen · Fußzeile
